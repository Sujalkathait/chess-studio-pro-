# Chess Studio Pro - Frontend ♞

This directory contains the React frontend for Chess Studio Pro.

## Setup & Run
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Features
- React + TypeScript + Vite
- Tailwind CSS styling with custom animations and responsive breakpoints
- Integrated Stockfish Web Worker (`stockfish.js`)
- Socket.io client for real-time multiplayer

Make sure the backend is running locally on port 3000 to enable the Online Multiplayer functionality during development.
